# ADR Review

## Reviewed

ADR 0013 (decisions are metadata only, client text is clipped) governs what is recorded: the id is validated
and bounded before it is used. ADR 0011 (selectors) is unaffected: a session id is not a selector fact.

## Outcome

No decision needs superseding and none is added: this widens which header names are read.
