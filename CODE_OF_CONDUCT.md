# Code of conduct

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be kind and assume good faith. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks, or unwelcome sexual attention.
- Do not publish other people's private information, and do not paste keys or credentials.
- Keep issues, pull requests and chat on topic and constructive.

This applies in the repository, in pull requests and issues, and in the project's
[Discord](https://discord.gg/qfTGr7KTfq).

## Enforcement

The maintainer may edit or remove comments, close issues, and remove people from the repository or
the Discord for behavior that breaks these rules. To report a problem, message the maintainer
privately on Discord or through a GitHub private message; reports are handled in confidence.
